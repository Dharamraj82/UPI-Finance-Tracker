"# UPI Finance Tracker

A full-stack app for tracking and analyzing UPI transactions, spending habits, and financial summaries.

## Project structure
- `FRONTEND/` – React + Vite frontend UI
- `EXPRESS_BACKEND/` – Express API server and data processing

## Features
- Upload and parse financial data
- Analyze spending patterns
- User dashboard and reports
- Responsive web interface

## Run locally
### Frontend
```bash
cd FRONTEND
npm install
npm run dev
```

### Backend
```bash
cd EXPRESS_BACKEND
npm install
npm start
```
